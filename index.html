Practical Guide

Perakitan Kabel LAN Crossover

Langkah pembuatan kabel LAN crossover.

01

Siapkan Alat dan Bahan

Kabel UTP/STP, tang crimping, LAN tester, dua buah RJ45 dan stripper.

02

Kupas Kabel

Kupas kulit kabel UTP/STP kurang lebih sepanjang dua ruas jari telunjuk.

03

Susunan Warna

UJUNG A
1. Putih-Oranye
2. Oranye
3. Putih-Hijau
4. Biru
5. Putih-Biru
6. Hijau
7. Putih-Coklat
8. Coklat

UJUNG B
1. Putih-Hijau
2. Hijau
3. Putih-Oranye
4. Biru
5. Putih-Biru
6. Oranye
7. Putih-Coklat
8. Coklat
04

Potong Kabel

Potong ujung kabel menggunakan tang crimping.

05

Masukkan ke RJ45

Masukkan kabel sesuai urutan warna ke konektor RJ45.

06

Crimping

Kunci RJ45 menggunakan tang crimping.

07

Test Kabel

Gunakan LAN Tester. Jika indikator menyala sesuai urutan, kabel siap digunakan.

⚙️ Konfigurasi


1. Sambungkan kedua laptop menggunakan kabel crossover.

2. Buka Control Panel.

3. Network and Internet.

4. Network and Sharing Center.

5. Change adapter setting.

6. Ethernet → Properties.

7. Internet Protocol Version 4.

8. Masukkan IP masing-masing laptop.

ping 198.168.10.1
ping 198.168.10.2

Jika mendapatkan Reply, koneksi berhasil.

File Sharing

Berbagi File Antar Dua Laptop

Cara membagikan file melalui jaringan LAN.

STEP 01

📁 Cari File

Cari file yang ingin dibagikan.

STEP 02

Give Access

Klik kanan → Give access to → Specific people.

STEP 03

Everyone

Pilih Everyone kemudian Add.

STEP 04

Read/Write

Pilih Permission Level Read/Write.

STEP 05

Share

Klik Share kemudian Done.

STEP 06

Laptop 2

Tekan Windows + R. Kemudian masukkan alamat komputer.

\\198.168.10.1
STEP 07

Network

Buka Network/User pada File Explorer.

STEP 08

Copy File

Copy file lalu paste ke folder Documents.

DONE

✅ Selesai

File berhasil dibagikan.
